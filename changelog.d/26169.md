section: rts
synopsis: Fix garbage GC CPU time when some GC threads are idle
issues: #26169
mrs: !16871
description: {
  The GC CPU time reported by ``+RTS -s`` and ``GHC.Stats`` could be huge or
  negative after ``setNumCapabilities`` when the GC thread count (``-qn``)
  was below the capability count. Each GC thread now accounts for its own
  CPU time, so idle threads no longer contribute.
}
